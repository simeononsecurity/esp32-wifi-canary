# WiFi Canary field card

Blue: learning the nearby access-point baseline.

Green: score 0 through 2.

Yellow: score 3 through 5.

Red: score 6 or higher.

One button press prints the access-point table and clears the score.

The device does not join WiFi networks. Production firmware does not transmit raw 802.11 frames.

Serial speed: 115200.

Commands: `dumplog`, `clearlog`.
